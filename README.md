# 📊 Livro de Contas

Um aplicativo web moderno, rápido e minimalista para controle financeiro pessoal e gerenciamento de lista de compras.

Este projeto foi construído para ser **100% privado e focado no usuário final**, rodando diretamente no navegador sem a necessidade de servidores ou bancos de dados externos, garantindo que os seus dados financeiros fiquem armazenados apenas no seu próprio dispositivo.

## ✨ Funcionalidades

* **📈 Dashboard Interativo:** Resumo automático de entradas, saídas, saldo do mês e saldo acumulado total.
* **📊 Gráfico de Despesas:** Visualização clara das despesas por categoria usando Chart.js.
* **🌓 Tema Claro/Escuro:** Interface fluida que se adapta à sua preferência visual com um simples clique.
* **⚡ Lançamentos Rápidos (Templates):** Botões pré-configurados (Mercado, Aluguel, Salário, etc.) para acelerar o preenchimento diário.
* **🛒 Lista de Desejos (Wishlist):** Uma aba dedicada para planejar compras futuras, separada por prioridades com cálculo automático.
* **🔒 Privacidade Total:** Todos os dados são salvos localmente no seu navegador via `localStorage`.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização moderna, variáveis CSS, animações e layout responsivo.
* **JavaScript (Vanilla):** Lógica de negócios e armazenamento de dados.
* [**Chart.js**](https://www.chartjs.org/): Biblioteca para renderização do gráfico de barras.

## 🚀 Como acessar e usar

A maneira mais fácil de usar o Livro de Contas é acessando a versão hospedada no GitHub Pages:

👉 [**Acessar o Livro de Contas**](https://dorfonaltz.github.io/meu-livro-de-contas/)

**Se preferir rodar localmente no seu computador:**

1. Faça o download ou clone este repositório:
   `git clone https://github.com/dorfonaltz/meu-livro-de-contas.git`
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador favorito.
