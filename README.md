📊 Livro de ContasUm aplicativo web moderno, rápido e minimalista para controle financeiro pessoal e gerenciamento de lista de compras.Este projeto foi construído para ser 100% privado e focado no usuário final, rodando diretamente no navegador sem a necessidade de servidores ou bancos de dados externos, garantindo que os seus dados financeiros fiquem armazenados apenas no seu próprio dispositivo.✨ Funcionalidades📈 Dashboard Interativo: Resumo automático de entradas, saídas, saldo do mês e saldo acumulado total.📊 Gráfico de Despesas: Visualização clara das despesas por categoria usando Chart.js (ativa automaticamente quando há saídas cadastradas).🌓 Tema Claro/Escuro: Interface fluida que se adapta à sua preferência visual com um simples clique.⚡ Lançamentos Rápidos (Templates): Botões pré-configurados (Mercado, Aluguel, Salário, etc.) para acelerar o preenchimento diário.🛒 Lista de Desejos (Wishlist): Uma aba dedicada para planejar compras futuras, separada por prioridades (Alta, Média, Baixa) com cálculo automático do valor estimado.🔒 Privacidade Total: Todos os dados são salvos localmente no seu navegador via localStorage.🛠️ Tecnologias UtilizadasEste projeto foi desenvolvido com foco em performance e simplicidade, utilizando apenas as tecnologias base da Web:HTML5: Estruturação semântica.CSS3: Estilização moderna, variáveis CSS para temas dinâmicos, animações e layout responsivo.JavaScript (Vanilla): Lógica de negócios, manipulação do DOM e armazenamento de dados.Chart.js: Biblioteca para renderização do gráfico de barras.🚀 Como acessar e usarA maneira mais fácil de usar o Livro de Contas é acessando a versão hospedada no GitHub Pages:👉 Acessar o Livro de Contas (Lembre-se de substituir este link pela sua URL gerada no GitHub Pages)Se preferir rodar localmente no seu computador:Faça o download ou clone este repositório:git clone https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
